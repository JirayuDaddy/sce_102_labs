## 📚  My Learning Resources & References

รายการแหล่งข้อมูล คอร์สเรียน และเอกสารอ้างอิงที่ใช้ในโปรเจกต์นี้:

- [CS50x: Introduction to Computer Science (Harvard)](https://cs50.harvard.edu/x/)  
  *ปูพื้นฐานวิทยาการคอมพิวเตอร์และภาษา C*
- [MIT 6.087: Practical Programming in C](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/)  
  *คอร์สเจาะลึกการใช้งานภาษา C จาก MIT OpenCourseWare*
- [Stanford CS107: Computer Organization & Systems](https://web.stanford.edu/class/cs107/)  
  *การทำงานของระบบ คอมไพเลอร์ และการจัดการ Memory*

  *แนวทางการเขียนภาษา C ยุคใหม่ (C11 / C17)*
